# 🌉 Zunda-Bridge

**Le pont commercial Russie-Afrique-Chine, propulsé par la crypto ZND**

Zunda-Bridge est une plateforme e-commerce qui permet aux Russes, Africains et Chinois d'acheter sur Wildberries, 1688 et Amazon en utilisant la crypto ZND.

## ✨ Fonctionnalités

- 🛒 Catalogue produits de Wildberries, 1688, Amazon
- 💳 Paiement en ZND (crypto)
- 🌍 Solutions spécifiques pour la Russie (contourner les sanctions)
- 🌍 Solutions spécifiques pour l'Afrique (protection contre l'inflation)
- 🔗 Intégration future avec BRICS Pay
- 🌐 Site trilingue (FR/EN/RU)

## 🚀 Déploiement

1. Clonez ce repository
2. Ajoutez les images dans `/assets/images/`
3. Configurez votre domaine dans les fichiers
4. Déployez sur Netlify, Vercel ou GitHub Pages
